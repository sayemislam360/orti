# Orthi Birthday Surprise Website

A romantic, responsive Bengali birthday surprise website for Orthi (Pakhi).

## Files
- `index.html` — page structure and Bengali messages
- `style.css` — responsive dreamy-pink styling and illustrations
- `script.js` — envelope, candle, and heart animations

## Run locally
Open `index.html` in a browser. An internet connection is needed for the Google Fonts; the site otherwise works without external assets.

## Publish with GitHub Pages
1. Create a new **public** repository on GitHub (for example `orthi-birthday`).
2. Upload these three files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish. Your site URL will look like `https://YOUR-USERNAME.github.io/orthi-birthday/`.

To change the letter, edit the text inside `letter-message` in `index.html`.
